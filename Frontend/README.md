# Avion International — Frontend

Production Next.js 16 App Router app. Active project phase is **Frontend only**.

## Commands

```bash
npm run dev
npm run typecheck
npm run lint
npm run build
npm run start
```

## Stack (pinned exact)

- Next.js 16.3.1 · React 19.2.8 · TypeScript strict · Tailwind 4.3.3 · Zod · CVA · Pino

## Structure

Follow `src/` enterprise layout and `.cursor/rules/frontend-production-rules.mdc`. Do not edit `Backend/` or `Database/` until phase unlock.
