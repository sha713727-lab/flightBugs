# Destination landing — Flights worldwide (`/en/europe`)

Example landing page. The main homepage at `/en` is unchanged.

## Business model (locked)

Avion International is a phone-first travel agency for Canada and the USA.

- Search live flights on the page
- A specialist tickets by phone — no website checkout, no airline check-in, no Sign In
- Award-winning service · 24/7
- Call +1 877 702 9887

Airline-only utilities from the source MD (Manage Booking, Check-in, Sign In) are not used.

## Destination (locked to existing assets)

Worldwide targeting. Desktop hero uses `destinationLandingHero.mp4`. Phones use `destinationLandingHeroMobile.mp4`. Featured cities are **London**, **Paris**, and **Tokyo**. Default search is Montreal (YUL) → Paris (CDG). Search still covers airports worldwide.

## Page structure

1. Slim announcement bar  
2. Sticky navigation (logo, in-page links, Search flights)  
3. Hero — Europe + overlapping search card  
4. Short editorial introduction  
5. Explore cities — London, Paris  
6. Why Avion — magazine layout  
7. Featured experiences — horizontal cards  
8. Flight / route information  
9. Best time to visit — four seasons  
10. FAQ accordion  
11. Final search CTA  
12. Footer — search, destinations, FAQ, call

## Visual

Premium editorial travel magazine + Avion search. Light page, aviation blue and white only (no yellow), white search card, cinematic hero overlay. Search remains the conversion entry; ticketing stays on the phone.
